## Project Description
The Banking Management System is a C++ console-based application developed as part of the CodeAlpha C++ Programming Internship. It provides basic banking operations for managing customers, accounts, deposits, withdrawals, transfers and transaction records.

## Features
- Create customer accounts.
- Store customer information.
- Deposit money.
- Withdraw money.
- Transfer funds between accounts.
- Display account information.
- View transaction history.
- Save transaction records in a file.

## Programming Language
- C++

## Concepts Used
- Object-Oriented Programming
- Classes and Objects
- Functions
- Conditional Statements
- Loops
- Vectors
- File Handling

## How to Run
1. Download or clone this repository.
2. Open `Banking_System.cpp` in Code::Blocks or Dev-C++.
3. Compile the program.
4. Run the application.
5. Select an option from the banking menu.
